## Proyectos

### [ProLink — Plataforma de servicios](https://github.com/wytreep/prolink-PL)
> Desde mayo de 2026. Backend y arquitectura.

- Lidero el diseño de la arquitectura y del modelo de datos relacional de una plataforma que conecta proveedores y clientes
- Construyo los endpoints principales de la API para autenticación segura y permisos por rol
- **Stack:** TypeScript, Node.js, NestJS, PostgreSQL

### [UNI-VIRTUAL — Plataforma académica (LMS)](https://github.com/wytreep/univirtual)
> Marzo a abril de 2026. Proyecto de Ingeniería de Software en la UNIAJC.

- LMS modular con arquitectura MVC en **PHP 8** y **React 18**, con 4 roles de usuario (Admin, Profesor, Estudiante, Directivo)
- **API REST** con más de 21 endpoints y streaming de video con HTTP Range
- Patrones de diseño (Singleton PDO, Template Method, Composite) y pruebas con Pytest, Playwright y Selenium
- **Scrum** en Jira durante 5 sprints

### Reity — App móvil de finanzas personales
> 2026 hasta hoy. En desarrollo.

- API REST: transacciones, categorías y presupuestos con alertas al 80 % y al 100 %
- Pantallas móviles de panel, transacciones y presupuestos
- Seguridad: protección contra fuerza bruta, bloqueo de cuenta, registro de auditoría, política de contraseñas, CORS estricto y recuperación de contraseña con código por correo
- **Stack:** React Native, Expo, NestJS, TypeScript, TypeORM, PostgreSQL, Redis
