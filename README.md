## Proyecto destacado

### [UNI-VIRTUAL — Plataforma LMS Universitaria](https://github.com/wytreep/univirtual)

> Sistema de gestión académica completo desarrollado para la UNIAJC como proyecto de Ingeniería de Software (2026).

- **PHP 8 POO** con arquitectura MVC de 3 capas (Singleton, Template Method, Composite)
- **REST API** con 21+ endpoints organizados por rol (Admin, Profesor, Estudiante, Directivo)
- **React 18 SPA** embebido — sin build step, directo sobre PHP
- **MySQL 8** con 13 tablas, FK constraints e índices optimizados
- **Videollamadas** integradas con Jitsi Meet (sin cuenta ni servidor propio)
- **Streaming de video** con HTTP Range requests (seeking nativo)
- **Reportes** PDF nativos con FPDF y exportación CSV/XLSX
- **Tests** con Pytest, Playwright y Selenium
- **Scrum** documentado: Jira board, sprints, criterios de aceptación
