## Proyectos destacados

### [Tienda Full-Stack — API REST de e-commerce](https://github.com/wytreep/tienda-fullstack)
> Backend de tienda en línea con pagos reales (2026).

- **NestJS + TypeScript:** API modular con control de acceso por roles (RBAC)
- **MercadoPago:** procesamiento de pagos y verificación en tiempo real con webhooks
- **PostgreSQL + Redis:** Redis como caché para lecturas frecuentes
- **Docker** para el entorno de desarrollo y panel de administración en React

### [UNI-VIRTUAL — Plataforma LMS universitaria](https://github.com/wytreep/univirtual)
> Sistema de gestión académica desarrollado para la UNIAJC como proyecto de Ingeniería de Software (mayo–agosto 2025).

- **PHP 8 (POO)** con arquitectura MVC (Singleton, Template Method, Composite)
- **API REST** con más de 21 endpoints organizados por rol (Admin, Profesor, Estudiante, Directivo)
- **MySQL 8** con 13 tablas, llaves foráneas e índices
- **Streaming de video** con HTTP Range y **videollamadas** con Jitsi Meet
- **Pruebas** con Pytest, Playwright y Selenium; **Scrum** en Jira (5 sprints)
